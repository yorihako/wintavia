# セキュリティ上の問題の報告 / Reporting security issues

Wintavia にセキュリティ上の問題（脆弱性）を見つけた場合は、**公開の issue には書かず**、GitHub の非公開の報告からお知らせください。

- [非公開で報告する（Report a vulnerability）](https://github.com/yorihako/wintavia/security/advisories/new)

報告には、Wintavia の版、Windows と Office の版、問題の内容と再現の手順を書いてください。会社の文書や個人情報は含めないでください。

Wintavia は無償で提供しているため、対応の時期はお約束できませんが、内容を確認し、必要に応じて修正版を公開します。

---

If you find a security vulnerability in Wintavia, **do not open a public issue**. Please report it privately:

- [Report a vulnerability](https://github.com/yorihako/wintavia/security/advisories/new)

Include the Wintavia version, the Windows and Office versions, a description and the steps to reproduce. Do not include company documents or personal information. Wintavia is provided free of charge, so we cannot promise a timeline, but we will review the report and publish a fix when needed.

## 対象の版 / Supported versions

最新の版だけを対象にします。 / Only the latest release is supported.
